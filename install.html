Android par install

Chrome me ye 3 step karo:

  1. Chrome ke upar-right me ⋮ (3 dots) dabao.
  2. "Install app" ya "Add to Home screen" chuno.
  3. "Install" dabao. Home screen par Mahakal Wellness icon aa jayega.

Menu me "Install app" na dikhe? Ya to app pehle se install hai (home screen / app list me Mahakal Wellness icon dhoondho), ya menu me "Open in Chrome" chuno. Chrome nahi hai? Link copy karke Chrome me kholo.

iPhone par install

Safari me ye 3 step karo:

  1. Neeche ka Share button dabao (□ ke upar tir).
  2. Neeche scroll karke "Add to Home Screen" chuno.
  3. Upar-right me "Add" dabao. Icon home screen par aa jayega.

iPhone par Safari me kholo

iPhone par app Safari browser se install hota hai.

  1. Neeche ka button dabake link copy karo.
  2. Safari kholo aur address bar me paste karo.
  3. Phir Share → Add to Home Screen → Add.

Computer par install

Chrome / Edge me address bar ke right side me install icon (⊕) dabao, ya menu ⋮ → Install Mahakal Wellness.
